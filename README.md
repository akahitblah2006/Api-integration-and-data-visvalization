# API Integration and Data Visualization 🌦️

## Project Overview

This project fetches real-time weather data for seven major Indian cities using the OpenWeatherMap API and visualizes temperature and humidity using graphs.

## Features

* Fetches weather data through an API.
* Collects temperature and humidity.
* Displays data in a table.
* Generates temperature and humidity comparison graphs.

## Technologies Used

* Python
* OpenWeatherMap API
* Requests
* Pandas
* Matplotlib
* Seaborn

## Cities Covered

Delhi, Mumbai, Kolkata, Chennai, Bengaluru, Hyderabad, and Ahmedabad.

## Project Output

* `temperature_chart.png` — Temperature comparison across cities.
* `humidity_chart.png` — Humidity comparison across cities.

## How to Run

1. Install Python.

2. Install the required libraries:

   `pip install requests pandas matplotlib seaborn`

3. Add your OpenWeatherMap API key to the Python script.

4. Run the program:

   `python "Api integration and data visvalization.py"`

## Objective

To demonstrate API integration, data collection, processing, and visualization using Python.
